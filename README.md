# 💱 ExConvert - Currency Converter

A modern and professional Currency Converter Web App built using React + Vite with real-time exchange rates, animated UI, country flags, swap functionality, and responsive fintech-style design.

---

## 🚀 Features

- 🌍 Real-time Currency Conversion
- ⚡ Fast React + Vite Performance
- 🎨 Modern Fintech UI Design
- 🔄 Currency Swap Button
- 🏳️ Country Flags
- ✨ Smooth Hover Animations
- 📱 Fully Responsive Design
- 🌙 Dark Gradient Theme
- 📊 Live Exchange Rate Cards
- 🕘 Conversion History
- ⚠️ Error Handling
- ⏳ Loading State

---

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- ExchangeRate API
